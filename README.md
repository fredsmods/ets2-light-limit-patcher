# ets2-light-limit-patcher

Raises the light list capacity of Euro Truck Simulator 2 (v1.62.3.3) above the default 480.
Confirmed working in game: 500 and 600 (window allows 480-1000, larger values untested).

Download the zip, extract the whole folder, close ETS2 and double-click Start-ETS2-Light-Patcher.bat.
A backup (eurotrucks2.exe.bak) is created automatically. Only ETS2 1.62.3.3 is supported.
Do not use a modified exe in multiplayer (e.g. TruckersMP). Use at your own risk.
